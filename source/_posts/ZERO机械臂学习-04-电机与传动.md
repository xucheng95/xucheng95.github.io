> 上一篇认识了物料清单，这一篇把"动力系统"讲透：**步进电机为什么能精确控制、减速器怎么放大扭矩、同步带轮怎么传动力**。读完你会明白代码里 `reduction_ratio`、`MOTOR_DIR_*` 这些字段到底对应机械上的什么。

## 1. 步进电机：能"数着步数"转的电机

### 普通电机 vs 步进电机

| | 普通直流电机 | 步进电机 |
|--|------------|---------|
| 控制方式 | 给电压就转 | 给脉冲序列才转 |
| 转多少 | 不可控（惯性大） | **每脉冲转固定角度，可控** |
| 典型应用 | 风扇、玩具 | 3D 打印机、机械臂、数控机床 |

**步进电机的核心原理**：内部有多组线圈（相位），按顺序通电，转子就一步步转动。

- 每给一个脉冲，转子转一个**步距角**（比如 1.8°）
- 给 200 个脉冲 = 转 360°（200 × 1.8°）
- 想转 90°？发 50 个脉冲就行

**代码对应**：`Emm_V5.c` 里控制电机转到指定角度，本质就是告诉驱动器"要转多少步"。

### 步距角（Step Angle）

ZERO 用的步进电机步距角一般是 **1.8°**（即每脉冲转 1.8°，200 步一圈）。但加了减速器后，输出端每脉冲转的角度变成了：

$$
\text{输出步距角} = \frac{\text{电机步距角}}{\text{减速比}} = \frac{1.8°}{51} ≈ 0.035°
$$

**这意味着**：减速比越大，输出分辨率越高（转得越精细），同时扭矩越大、转速越慢。这就是为什么负载大的关节需要大减速比。

## 2. 减速器：把"高速小力"变成"低速大力"

### 为什么要减速

电机天生"高转速、小扭矩"。机械臂需要的是"低转速、大扭矩"——要稳稳托住手臂和负载。

减速器就是一台"扭矩放大器"：

$$
\text{输出扭矩} = \text{电机扭矩} \times \text{减速比}
$$

$$
\text{输出转速} = \frac{\text{电机转速}}{\text{减速比}}
$$

### 行星减速器：ZERO 用的类型

**行星减速器**是一种高精度、小体积的减速器，结构像太阳系：

```
      ┌── 太阳轮（输入，电机轴）──┐
      │     ↙ 行星轮 ×3 ↖         │
      └── 齿圈（固定）──────┘
           ↓ 行星架（输出，连关节）
```

- 电机轴带动中心的**太阳轮**
- 太阳轮驱动 3 个**行星轮**（同时绕自身转 + 绕太阳公转）
- 行星轮带动**行星架**输出

好处：多个行星轮分摊负载 → 体积小、扭矩大、精度高、同轴输入输出。非常适合机械臂这种紧凑场景。

### 减速比在代码里

```c
// robot.c 关节配置表
{90, MOTOR_DIR_CCW, 50,    ..., 0, 360, DIR_NEGATIVE},  /* 关节1：减速比50 */
{90, MOTOR_DIR_CW,  50.89, ..., 90, 180, DIR_NEGATIVE},  /* 关节2：减速比50.89 */
{90, MOTOR_DIR_CCW, 26.85, ..., 0, 90,  DIR_POSITIVE},  /* 关节5：减速比26.85 */
```

**50.89 这种小数哪来的？** 减速比 = 齿圈齿数 / 太阳轮齿数，比如齿圈 96 齿、太阳轮 33 齿……不对，标准公式是：

$$
\text{减速比} = \frac{Z_{\text{齿圈}}}{Z_{\text{太阳轮}}} + 1
$$

比如齿圈 96、太阳轮 34：$\frac{96}{34} + 1 ≈ 3.82$？不对。实际行星减速器减速比的计算因结构而异，**50.89 大概率是实测校准出来的值**——作者用角度传感器实测"电机转 N 圈、关节转多少度"反推的。这也是为什么不同批次的减速器要微调这个值。

> **实操提示**：你买到手的减速器如果和代码里的减速比略有出入（比如标称 51，代码写 50.89），联调时先按代码跑，如果发现"命令转 90° 实际转 89°"，就去改这个数字。这是复刻时非常常见的校准项。

## 3. 闭环控制：张大头驱动器为什么"聪明"

### 开环 vs 闭环

| | 开环 | 闭环 |
|--|------|------|
| 有没有反馈 | 没有 | **有编码器测量实际位置** |
| 丢步了怎么办 | 不知道，继续走 | **检测到误差，自动纠正** |
| 精度 | 一般 | 高 |

步进电机有个天然缺陷：负载过大时会"丢步"——脉冲发了但电机没跟上，位置就错了。开环系统无从察觉。

**张大头是闭环驱动器**：电机尾部带**编码器**（一个测量转角的传感器），驱动器随时知道电机实际转到哪。发现实际角度和指令角度有偏差 → 立即补偿。这就是它叫"闭环"的原因。

```
指令角度 ──→ [比较器] ──→ 驱动器 ──→ 电机 ──→ 关节
                 ↑                              │
                 └──── 编码器测量实际角度 ←──────┘
```

### 代码里的闭环体现

`Emm_V5.c` 有读取电机状态、清除堵转保护等命令——这些都是在利用闭环能力。比如：

```c
Emm_V5_Reset_Clog_Pro(addr);   // 解除堵转保护：电机被卡住后，恢复前先解除保护
```

电机堵转（被卡死）时闭环驱动器会进入保护状态，需要发这个命令解除。

## 4. 同步带轮：把动力"拐个弯"

### 为什么要同步带

机械臂的关节处空间极其紧凑，电机没法直接装在关节旋转轴上。**同步带**允许电机装在旁边，通过带子把动力传到关节轴：

```
    [电机]──同步轮A（小）
             │
      同步带（带齿）
             │
    [关节轴]─同步轮B（大）
```

### 同步轮 vs 皮带轮

**同步轮是有齿的**（3M = 齿距 3mm），同步带内表面也有对应的齿，两者啮合——**不打滑**。皮带轮靠摩擦力传动，重载会打滑，角度就不准了。

**孔径的区别**：同步轮中心的孔要套在轴上。BOM 里 8mm、5mm、6mm 三种孔径对应不同粗细的电机轴/关节轴。**买之前必须量轴的直径**，装不进去就麻烦了。

### 同步带传动的减速效果

如果电机端同步轮 25 齿、关节端同步轮也是 25 齿（BOM 里都是 25 齿），那传动比是 1:1，**同步带不改变减速比**——它只负责"拐弯传力"，减速全靠减速器。

## 5. 联轴器：把电机轴和负载轴"抱"在一起

### 是什么

一个带螺丝的圆柱连接件，一端锁电机轴，一端锁减速器/关节轴：

```
[电机轴]──║联轴器║──[负载轴]
          ║  ║
         螺丝锁紧
```

### 为什么不能直接焊接/硬连

电机轴和负载轴**不可能绝对同心**（有微小偏差），硬连会导致振动和损坏。联轴器允许微小偏差，同时传递扭矩。抱紧式 = 用螺丝从侧面锁紧，简单可靠。

## 6. 动力系统的完整链路（一个关节为例）

以关节 2（42 电机 + 51:1 行星减速器 + 同步带）为例：

```
张大头驱动器
   │  CAN 收到指令："转到 +30°"
   ▼
42 步进电机
   │  每脉冲 1.8°，闭环编码器实时校正
   ▼
行星减速器（51:1）
   │  扭矩 ×51，转速 ÷51
   ▼
同步轮 A（25齿，孔径5mm）──同步带──同步轮 B（25齿，孔径8mm）
   │  1:1 传动，动力拐弯
   ▼
关节轴 → 关节转动 30°
```

**代码视角**：主控算好"关节 2 应该转 30°" → 换算成"电机实际要转 30° × 51 = 1530°（4.25 圈）" → 通过 CAN 发给驱动器 → 电机转 4.25 圈 → 关节转 30°。**这个 51 就是 `reduction_ratio`**。

## 7. 常见问题

**Q: 为什么关节 1 用减速比 50，而关节 5 只有 26.85？**
关节 1 扛着整条手臂，需要最大扭矩 → 大减速比。关节 5 只转末端小爪，负载小 → 小减速比，响应还更快。

**Q: 步进电机和伺服电机有什么区别？**
伺服电机（带编码器的无刷电机）性能更好但贵得多。步进 + 闭环驱动是低成本机械臂的务实选择，ZERO 用张大头闭环方案就是用"步进的价格"获得接近伺服的精度。

**Q: 怎么判断电机装反了？**
发 `rel_rotate 1 30`（关节 1 转 30°），如果关节转了 -30°，就是方向反了。改代码里关节表的 `MOTOR_DIR_CCW`/`MOTOR_DIR_CW`，或调整电机接线。
