> 本篇用程序员的直觉讲清楚机器人学最核心的三个概念：**自由度、坐标系变换、正逆运动学**。读完你就能看懂 `robot_kinematics.c` 在算什么。不需要任何数学基础，所有公式都有"人话版"解释。

## 1. 自由度（DOF）：机器人有多少个"能动的关节"

### 人话版

自由度 = 机器人能独立运动的关节数量。ZERO 有 **6 个旋转关节**，所以是 **6 自由度（6-DOF）机械臂**。

你可以把每个关节想象成你的胳膊：

| 你的身体 | 机械臂 | 自由度 |
|---------|--------|--------|
| 肩膀（可转） | 关节 1、2、3 | 3 |
| 肘部 | 关节 4 | 1 |
| 手腕 | 关节 5、6 | 2 |
| **合计** | | **6** |

### 为什么是 6？

因为**在三维空间中，要让末端（抓手）到达任意位置并摆出任意姿态，正好需要 6 个独立量**：

- 位置：x、y、z（3 个量）
- 姿态：绕 x/y/z 轴的角度（3 个量）

3 + 3 = 6，所以 6 自由度是"完整"的机械臂。少于 6 只能到特定位置，多于 6（如人形机器人）是冗余——同一个位置有多种关节摆法。

### 在代码里

```c
#define ROBOT_MAX_JOINT_NUM 6   // robot.h
```

代码里所有数组都是 6 个元素：`g_robot.joints[6]`、`joint_weight[6]`。

## 2. 坐标系：机器人的"定位系统"

### 人话版

机械臂要在空间里运动，必须有个"尺子"来量位置。这个尺子就是**坐标系**——一个原点 + 三个互相垂直的方向（x/y/z）。

每个关节都有自己的坐标系，机械臂的结构就是**一串坐标系互相连接**：

```
坐标系0（底座）→ 坐标系1（关节1后）→ 坐标系2（关节2后）→ ... → 坐标系6（末端）
```

当关节 1 转动时，它**后面所有坐标系都跟着动**。这就是"链式"结构——运动学计算的本质就是处理这个链条。

### 旋转矩阵：描述"转动"的数学工具

关节转动 = 坐标系绕某个轴转一个角度。绕 z 轴转 $\theta$ 角的变换是：

$$
R_z(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix}
$$

**程序员视角**：这不过是一个 3×3 的矩阵，把坐标向量 $(x, y, z)$ 左乘它，就得到旋转后的新坐标：

```python
import numpy as np
theta = np.pi / 2          # 90度
Rz = np.array([[np.cos(theta), -np.sin(theta), 0],
               [np.sin(theta),  np.cos(theta), 0],
               [0,             0,             1]])
p = np.array([1, 0, 0])    # 一个点
p_new = Rz @ p             # 旋转后的点
print(p_new)               # [0, 1, 0] —— 从x轴转到了y轴
```

这就是机器人学的"hello world"。

### 齐次变换矩阵：旋转 + 平移一网打尽

实际中每个关节既转动又平移（比如连杆有长度），把旋转矩阵和平移合并成一个 4×4 矩阵：

$$
T = \begin{bmatrix} R_{3\times3} & p_{3\times1} \\ 0 & 1 \end{bmatrix}
$$

左上 3×3 是旋转，右上 3×1 是平移。**这就是 `robot_kinematics.c` 里的 `g_robot_kinematics.T[4][4]`**。

## 3. 正运动学（Forward Kinematics）：已知角度 → 求末端位置

### 人话版

**问题**：已知每个关节转了 $\theta_1, \theta_2, ..., \theta_6$，问末端在哪里？

**答案**：把 6 个关节的变换矩阵按顺序乘起来：

$$
T_{0\to6} = T_1(\theta_1) \cdot T_2(\theta_2) \cdot T_3(\theta_3) \cdot T_4(\theta_4) \cdot T_5(\theta_5) \cdot T_6(\theta_6)
$$

矩阵乘法串联 = 沿着机械臂链条一站一站走过去，最后得到末端相对于底座的位置。

**类比**：你按"先向左转 30°，再走 2 米，再向上抬手 45°"的指令行动，最后你在哪——这就是正运动学。

### 在代码里

```c
// robot_kinematics.c
static void robot_kinematics_calc_theta3(void) { ... }  // 每算一个关节角
```

代码把 $\theta_3$、$\theta_4$ 等逐个求出来，最终填充 `T[4][4]` 矩阵。

## 4. 逆运动学（Inverse Kinematics）：已知末端位置 → 求各关节角度

### 人话版

**问题**：我想让末端到达点 $(x, y, z)$，每个关节该转多少度？

**答案**：这是正运动学的**反问题**——解方程。比正运动学难得多，因为：

1. **可能无解**：目标点在机械臂够不到的地方（超出工作空间）
2. **可能多解**：同一个点，机械臂可以"弯腰够"也可以"伸懒腰够"（肘上/肘下两种姿态）
3. **计算复杂**：涉及解三角函数方程组

**类比**：你站在房间里，想用手摸到天花板上的一个点——你的肩膀、肘、手腕各要弯多少？可能有几种弯法都能摸到。

### 多解问题在代码里

`robot_kinematics.c` 特意求出了**多组解**：

```c
#define ROBOT_KINEMATICS_RESULT_NUM 8   // 最多8组解
```

为什么是 8？因为有的关节角度在方程里有 $\pm$ 两个解，组合起来就是 2×2×2 = 8 组。代码再根据**关节角度限制**（每个关节只能转到某个范围）筛选出合法解。

### 代码里的关键常量

```c
// robot_kinematics.c 开头
#define a2 D_H[2][0]   // 连杆2长度
#define a3 D_H[3][0]   // 连杆3长度
#define d4 D_H[3][2]   // 连杆4偏距
```

这里的 `D_H` 就是 **DH 参数表**——用 4 个参数（a、alpha、d、theta）描述每段连杆的几何关系。这是机器人学的标准建模方法，下一篇会细讲。

## 5. 工作空间（Workspace）：机械臂"够得着"的范围

机械臂末端能到达的所有点的集合叫工作空间。受两个因素限制：

1. **连杆长度**：手臂越长，工作空间越大
2. **关节角度限制**：`robot.c` 里每个关节有 `min_angle` 和 `max_angle`（比如关节 5 只能转 0°~90°）

```c
// robot.c 关节配置表（节选）
{90, MOTOR_DIR_CCW, 50, ..., 0,   360, DIR_NEGATIVE},  /* 关节1：可转0~360° */
{90, MOTOR_DIR_CW, 50.89, ..., 90, 180, DIR_NEGATIVE},  /* 关节2：只能转90~180° */
```

联调时发 `auto x y z` 命令，如果目标点在工作空间外，机械臂会拒绝执行或报错——这就是工作空间在起作用。

## 6. 三个概念串起来看

```
你输入目标坐标 (x, y, z)
        │
        ▼
  逆运动学  ←←← 本篇第4节（难，多解）
        │  算出每个关节角度 θ1~θ6
        ▼
  发给电机 → 电机转到目标角度
        │
        ▼
  正运动学  ←←← 本篇第3节（简单，唯一解）
        │  验证末端实际位置
        ▼
  实际位置 ≈ 目标位置 ✅
```

**理解要点**：逆运动学是"规划"，正运动学是"验证"。控制器的核心逻辑就是反复做这两件事。

## 7. 动手实验（纯软件，10 分钟）

不需要硬件！用 Python 感受一下矩阵旋转：

```python
import numpy as np

def rot_z(theta_deg):
    t = np.radians(theta_deg)
    return np.array([[np.cos(t), -np.sin(t), 0],
                     [np.sin(t),  np.cos(t), 0],
                     [0,         0,         1]])

# 模拟两连杆：每根长1，转30°和45°
p = np.array([0.0, 0.0, 0.0])  # 从原点出发
p = p + rot_z(30) @ np.array([1, 0, 0])   # 第一根连杆末端
p = p + rot_z(30 + 45) @ np.array([1, 0, 0])  # 第二根连杆末端（角度叠加）
print(f"末端位置: ({p[0]:.2f}, {p[1]:.2f}, {p[2]:.2f})")
```

这就是一个简化版**正运动学**——你刚亲手算出了两连杆机械臂的末端位置。
