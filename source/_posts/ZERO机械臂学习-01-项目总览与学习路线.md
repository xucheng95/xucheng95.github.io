> 这是「ZERO 机械臂学习之路」系列的第一篇。本系列以一个真实开源项目——零一造物 ZERO 机械臂为教材，从零开始掌握机器人技术并完整复刻一台机械臂。目标读者：有编程经验、没碰过硬件的新手。

## 1. 这个项目是什么

ZERO 机械臂是 B 站 UP 主「零一造物」开源的一台桌面级六轴机械臂，主打**高性价比**（整套物料约 1300 元）和**学习导向**——把机器人领域的核心知识串起来：结构设计 → 运动学 → 控制 → 强化学习 → 大模型。

开源仓库内容一览：

| 目录 | 内容 | 你要学的 |
|------|------|---------|
| `1. Model` | SolidWorks 三维模型 + 3D 打印件 | 结构设计、装配 |
| `2. Software/robot` | STM32 嵌入式控制代码（C + FreeRTOS） | 嵌入式、控制 |
| `3. Simulink` | MATLAB 运动学推导与仿真 | 运动学、仿真 |
| `4. Other` | 图片资料 | — |
| `5. Deep_LR` | 强化学习（MuJoCo + TD3） | 强化学习 |
| `BOM.xlsx` | 完整物料清单（含购买链接） | 采购 |

## 2. 为什么用它当教材

作为新手，选学习项目最怕两件事：**代码太乱看不懂**，或**文档太全反而无从下手**。ZERO 的优点是：

1. **代码量恰到好处**：核心代码约 2700 行，一天读一小段，三个月能通读
2. **架构标准**：STM32CubeMX 生成 + FreeRTOS 实时系统，是工业界最常见的技术栈
3. **交互简单**：串口发一行文本命令就能控制，调试门槛极低
4. **全链路覆盖**：从电机转动到强化学习，一条线学到底

## 3. 技术全景图

复刻这台机械臂，你会接触到这些技术，它们的关系如下：

```
你（发命令）
   │  串口文本命令："auto 0 0 200"
   ▼
STM32 主控（机器人"大脑"）
   │  解析命令 → 运动学逆解（算每个关节该转多少度）
   │  → PID 控制（让电机平滑转到目标角度）
   ▼
CAN 总线（一条双绞线，连所有电机）
   ▼
张大头闭环步进电机 ×6（机器人"肌肉"）
   │  每个电机带减速器 → 驱动关节转动
   ▼
机械臂本体（3D 打印结构件）
```

对应代码文件：

| 环节 | 代码文件 |
|------|---------|
| 命令解析 | `Core/Src/robot_cmd.c` |
| 运动学逆解 | `Core/Src/robot_kinematics.c` |
| PID 控制 | `Core/Src/robot.c`（`robot_pid_one_period`） |
| CAN 通讯 | `Core/Src/can.c`、`Core/Src/Emm_V5.c`（张大头协议） |
| 主任务调度 | `Core/Src/freertos.c`（FreeRTOS 任务） |

## 4. 这台机械臂有多少个"自由度"

**六轴**（6 个旋转关节），比常见的四轴机械臂多两个，能实现更多姿态。6 个关节由 6 台电机驱动，但**不是同一型号**——因为越靠近底座要承受的负载越大：

| 关节 | 电机 | 减速比 |
|------|------|--------|
| 关节 1（底座） | 42 行星减速步进电机 | 50:1 |
| 关节 2 | 42 步进电机 + 行星减速器 | 51:1 |
| 关节 3 | 42 步进电机 + 行星减速器 | 51:1 |
| 关节 4 | 35 行星减速步进电机 | 51:1 |
| 关节 5 | 35 步进电机 + 行星减速器 | 27:1 |
| 关节 6（末端旋转） | 35 行星减速步进电机 | 51:1 |

> 为什么要减速比？电机转速高、扭矩小，减速器把转速降下来、扭矩放大，机械臂才能稳稳举起负载。这个"减速比"在代码里对应 `robot.c` 中的 `reduction_ratio` 字段，联调时如果角度不准，多半就是它没对齐。

## 7. 新手常见疑问速答

**Q: 我没有 3D 打印机怎么办？**
淘宝有 3D 打印代打服务，把 `1. Model/3d_printing_all.3mf` 发给店家，选 PLA 材料即可，约 50~100 元。

**Q: 完全没有硬件基础，能学会吗？**
能。嵌入式 C 代码本质 = 你熟悉的编程范式（状态机、队列、回调）+ 硬件寄存器。本系列会逐个概念讲清楚。

**Q: 一定要用指定的"张大头"驱动器吗？**
是的。项目代码（`Emm_V5.c`）是针对张大头闭环驱动器的私有 CAN 协议写的，换品牌需要改写协议层。这是复刻中最容易买错的地方，下单时务必确认是"CAN 协议版"。

**Q: 学完能干什么？**
能独立完成：STM32 嵌入式开发、CAN 总线通讯、运动学控制、强化学习训练。这些都是机器人行业的基础能力。
